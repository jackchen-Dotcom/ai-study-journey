二分循环条件怎么写？值条件为什么不行？	`while left <= right`（范围还有效）。值条件（mid*mid<x 等）会跳过循环或死循环——#35 首版、#69 TLE 都栽在这
二分三形态的断层线方向？	#35 插入位置 → left；#278 第一个满足（坏版本）→ left；#69 最后一个满足（i²≤x）→ right（= left−1）。先问方向，再写 return
二分收缩公式？	left = mid + 1 / right = mid − 1，永远边界 ±1。写 mid//2 是概念混乱
进位模拟骨架（#66/#67 通用）？	从末位起——是基数（9）就归 0 继续往前；非基数直接 +1 收工；一路到头全进位 → 新数组前面插 1
哑结点治什么病？	消灭"第一个结点"的特殊性（删头不用特判）。同族思想：特殊情况挪到循环外消灭
快慢指针两流派？	差速（快2慢1）找相遇/中点（#876）；同速错位 n 找倒数第 n+1 个结点即前驱（#19）
相向双指针的适用信号？	有序 + 极值在两端（#977 平方U形）。套模板前先验证前提（单调性/两端性）——#977 首版教训
链表踩尾退出的坑？	while p1: p1=p1.next 退出时 p1=None 不是尾结点。要尾就先存（tail=p1）或用 while p1.next——#61 载在这
字符串分段的状态机双变量？	当前段长度（易失，分隔符清零）+ 最近完整段长度（持久，不清零是正确性来源）——#58
反向遍历的收益？	提前返回（只扫尾部，1GB 只扫几个字符）+ 复用"计数≠0 才返回"化解尾部空格/零
/ 和 // 的区别 + 版本坑？	/ 真除法永远 float；// 地板除 int。力扣 "Python"(=2.7) 的 / 是整除能过，Py3 必炸——二分 mid 必须 //
类 vs 实例一句话？	类名无括号 = 图纸（赋值只是别名）；有括号传参 = 调 __init__ 造盒子。两次踩坑（LLM_client、ListNode）
变量三权分立 + 反面？	一变量一职责，乱不乱看职责归属（chatbot 的 messages、#977 的 i）；反面：职责重合就合并（#58 反向版 t/tmp 恒等，单变量够）
result = nums 会怎样？	贴标签不拷贝——写 result 就是写 nums，原数组被污染。独立副本用 [0]*n
s[::-1] vs reversed(s) 内存？	字符串不可变，切片整串复制（峰值×2）；reversed 是游标 O(1) 按需吐。单遍用 reversed，反复用/随机访问才切片
append / sort 的返回值？	None（原地修改）——别赋值回去（self.history = history.append(x) 双重错）
2^16 在 Python 是多少？	18（^ 是异或）。幂是 2**16 = 65536
Python 负索引的险处？	nums[-1] 不报错、摸末位——越界错误悄然发生。先判界再访问（#66 的 len1==0 拦截）
模型的"记忆"存在哪？	不在模型里——在程序的 history 列表，每轮全量重发。模型每次都是初次见面
对话 1000 轮会发生什么？	history 无限膨胀、成本平方级、超上下文窗口后报错或截断失忆 → Context Engineering 的动机
MCP 和 A2A 各管什么？	口诀"MCP 调工具，A2A 调 Agent"
role 三标签分工？	system 人设（1条，最前）/ user 用户说的（每轮）/ assistant 模型说的（每轮）。贴错标签 = 人格劈叉
temperature 是什么？	采样随机度——低值近似确定，高值发散。（实验结论待补：⬜）
