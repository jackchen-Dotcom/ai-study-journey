# 思路库（解题模式积累）

> 使用规则：每学会一个新套路，由**你自己**复述并写进这里（我可以帮你润色）。
> 每周测验时，我会从这里抽问某个模式的「适用信号」。

## 反向/相邻遍历 + 状态变量
- 适用信号: **一次遍历就能搞定，且当前位置怎么处理只取决于相邻位置（或之前维护的某个状态）**——我自己的话：上一位与下一位有强烈关联的时候
- 核心想法: 遍历时只维护一个（或少数几个）状态变量，每个元素只结算一次。这个模式是后面动态规划的地基
- 常见状态变量:
    - 前一个值（13.罗马数字：pre_val 决定当前值加还是减）
    - 前缀最小值（121.买卖股票：记录历史最低价）
    - 以 i 结尾的最优子问题（53.最大子数组和，DP 雏形）
- 模板代码:
    pre_val = 初始状态
    for x in 数据:        # 顺序或 reversed() 都可能
        决定当前 x 如何贡献（比较 x 与 pre_val）
        更新 ans
        pre_val = x       # 别忘了更新状态
- 我踩过的坑: 字典取值写成 map(x)；赋值方向写反 cur = pre_val；循环体缩进跑出方法
- 见过的题: 13.罗马数字转整数（从右往左）；121.买卖股票（待做）

## 栈：最近匹配（2026-09-03，#20）
- 我的话: 先入后出，像是套垃圾袋，最先套进去的最后扔
- 适用信号（补充）: 出现"最近的一个必须最先被匹配"或嵌套结构（括号、撤销、路径回退）
- 见过的题: 20.有效的括号
- 我踩过的坑: 忘了入栈动作；`is None` ≠ 空列表（判空用 `if not stack`）；pop 前不判空会 IndexError

## 哑结点：消灭第一次特殊性（2026-09-03，#21）
- 我的话: 在合并链表中，为了消除第一次的特殊，便于连接节点
- 补充: 代价是多造一个节点，最后 return dum.next；凡是"结果头不确定"的场景都能用
- 见过的题: 21.合并两个有序链表
- 我踩过的坑: ListNode[0] 应为 ListNode(0)（()创建，[]取值）；循环结束后剩余链尾要整队接入

## 快慢指针：原地搬运（2026-09-03，#26/#27）
- 我的话: 适用于原地算法，原地进行改动，不消耗更多的内存；慢指针为了确定最后的输出，快指针为了遍历整个数组
- 精确版（补充）: 慢指针守"保留区边界"（决定往哪写），快指针逐个探测；返回值看 slow 定义——末尾下标则 +1，写入计数则原样
- 见过的题: 26.删除有序数组中的重复项、27.移除元素（力扣一次通过）
- 我踩过的坑: 快指针不前进会卡死；写0=毁数据；for n in nums 的 n 是元素不是下标（栽过3次）

## 二分查找：范围收缩 + 断层线（2026-09-05，#35/#278/#69）
- 适用信号: 有序 + 找位置/找边界 + 数据量大。套模板前先验前提：**有单调分界吗？**（#977 教训：平方后 U 形非单调，二分前提崩，必须换武器）
- 三形态断层线: #35 插入位置 → left；#278 第一个满足（坏版本）→ left；#69 最后一个满足（i²≤x）→ right（=left−1）。**先问方向，再写 return**
- 骨架: 门上只挂 `while left <= right`（值条件会死循环：#35 首版、#69 TLE）；`mid = (l+r)//2`；收缩永远 ±1
- 我踩过的坑: 值条件死循环两连；return 方向反；`2^16` 是异或（=18）不是幂，幂是 `**`

## 快慢指针两流派（2026-09-04，#876/#19）
- 流派 A 差速（快2慢1）: 找相遇/中点（#876）
- 流派 B 同速错位 n: 快指针先走 n 步拉开差距，找倒数第 n+1 个（前驱）（#19）
- 我踩过的坑: 移动局部变量≠修改链表；踩尾退出时 p1=None 不是尾结点（#61 又栽）

## 相向双指针：两端向中心（2026-09-06，#977）
- 适用信号: 有序 + 极值只能出现在两端（平方 U 形，最大值在 |负| 或 正 端）
- 骨架: 谁大谁填 result **末尾**（从后往前填），指针内移；填位每轮 −1
- 我踩过的坑: `result = nums` 是贴标签不是拷贝（写 result 污染原数组，要 `[0]*n` 新建）；i 一人分饰三角导致元素被跳过

## ⭐ 变量三权分立（我的洞察，2026-09-06/07）
- 我的话: 一个参数无法达成目的时，不如几个参数分开执行，**不要怕参数太多太乱**
- 润色: 一变量一职责，乱不乱看变量个数，看职责有没有归属。写码前先列角色表：它是什么、诞生在哪、谁有权动它
- 反面: 职责重合就合并（#58 反向版 t/tmp 恒等，单变量够）——独立才拆，重合即合
- 实战: chatbot 的 messages（输入+历史混用）拆成 history+user_input；#977 的 i（指针+偏移+计数）拆成 left/right/fill

## 卫语句 + 坐标系换算（2026-09-08，#61）
- 卫语句: 函数开头拦"不需要干活"的情况（`if not head or k==0 or not head.next: return head`），主逻辑放心假设健康输入。or 短路求值 → **条件顺序 = 依赖顺序**（被访问的先判非空）
- 下刀法（旋转/搬移）: ①闭环（尾接 head）②走 length−k−1 步找新尾 ③新头=新尾.next，断开
- 坐标系: k 数的是新链坐标，下刀用原链坐标——**倒数第 m 个 = 正数下标 length−m**。旋转题的坑全在坐标系统一，动笔前画 5 结点方框图

## 进位模拟三件套（2026-09-07/08，#66/#67）
- 骨架: ①对齐（反转字符串 `a[::-1]`，或偏移 `n-len(a)+i`）②从末位逐位三数相加，`sum%2` 写本位、`sum//2` 传进位 ③循环外尾进位收尾（前置 '1'）
- 我踩过的坑: 对齐公式 `n-1-i` 是**镜像反转**——enumerate 从最高位字符起，n-1-i 送最低位，正确是 `n-len(a)+i`；`''.join(str(x))` 单字符=没拼（join 参数必须是序列，元素全 str）；reversed 返回迭代器不是 str；无进位时多开的格子别 join 进去（前导零）
- 见过的题: 66.加一（十进制）、67.二进制求和；同族待做：415.字符串相加、43.字符串相乘

## Python 坑速查（血泪合集，2026-09-05~08）
- 类名无括号 = 图纸不是盒子（踩 2 次：LLM_client、ListNode）
- `/` 真除法永远 float；`//` 地板除 int。力扣 "Python"=2.7 的 / 是整除，Py3 必炸——mid 必须 `//`
- append/sort 返回 None（原地修改），别赋值回去（踩 3 次：chatbot、#67 两版）
- `result = nums` 贴标签污染原数组；独立副本 `[0]*n`
- 负索引不报错、悄悄摸末位——先判界再访问（#66 的 len1==0 拦截）
- ⭐ **推演一百遍不如跑一遍：测试用例是唯一真相**（#67 事故：人脑走查和 AI 走查双双判对，实测 10010 才现形）

## 动态规划入门：五步法 + 适用雷达（2026-09-09，#70）
- 适用雷达（五大信号）: ①计数"多少种方法" ②最值"最少/最多/最长" ③可行性"能否达成" ④大问题=有限种前情的组合（最后一步来源有限）⑤n 大、暴力枚举是指数级。**一句话：问"数"而不是问"路"**——要数字找 DP，要方案清单找回溯
- 五步法: ①定义状态 dp[i]=到第 i 个…的方法数/最优值 ②转移方程（最后一步怎么来的）③初始化（手数最小子问题）④从小到大遍历 ⑤返回 dp[n]
- 本题: dp[i]=dp[i-1]+dp[i-2]（最后一步迈 1 或 2）；空间优化：只存前两阶 prev/curr
- 反信号: 只要一条具体走法 → 贪心；要所有方案清单 → 回溯；n≤20 → 暴力直过
- 我踩过的坑: 首版用组合枚举 x*(2y) 计数——排列数应是组合数 C(x+y,y)，且漏 y=0；补丁叠奇偶分支不如公式统一（修根因别叠补丁）
- 见过的题: 70.爬楼梯；同族待做：62.不同路径、53.最大子数组和、322.零钱兑换、198.打家劫舍、139.单词拆分
