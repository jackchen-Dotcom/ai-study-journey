## 一、算法模式（10 张）

**Q1 二分循环条件怎么写？值条件为什么不行？**
A：`while left <= right`（范围还有效）。值条件（如 `mid*mid < x`）会跳过循环或死循环——#35 首版、#69 TLE 都栽在这。

**Q2 二分三形态的断层线方向？**
A：#35 插入位置 → left；#278 第一个满足（坏版本）→ left；#69 最后一个满足（i²≤x）→ right（= left−1）。先问方向，再写 return。

**Q3 二分收缩公式？**
A：`left = mid + 1` / `right = mid − 1`，永远边界 ±1。写 mid//2 是概念混乱。

**Q4 进位模拟骨架（#66，#67 通用）？**
A：从末位起——是进位基数就归 0 继续往前；非基数直接 +1 收工；一路到头全进位 → 新数组前面插 1。

**Q5 哑结点治什么病？**
A：消灭"第一个结点"的特殊性（删头不用特判）。同族思想：#58 的前置特判——特殊情况挪到循环外消灭。

**Q6 快慢指针两流派？**
A：差速（快 2 慢 1）找相遇/中点（#876）；同速错位 n 找倒数第 n+1 个（前驱）（#19）。

**Q7 相向双指针（两端向中心）的适用信号？**
A：有序 + 极值在两端（#977 平方 U 形）。前提验证：两端可比较且答案可从两端构建——套模板前先验。

**Q8 链表踩尾退出的坑？**
A：`while p1: p1 = p1.next` 退出时 p1 = **None** 不是尾结点。要尾就得先存（`tail = p1`）或用 `while p1.next`。#61 载在这里。

**Q9 反转链表三指针各干什么？（#206）**
A：prev = 已反转段的头 / cur = 待处理 / nex = **断链前先存**。循环只做三件事：存 nex → cur.next 指 prev → 三指针各前进一步。首版翻车的坑：改局部变量 ≠ 改 .next。

**Q10 区间反转的"三定位 + 两刀接缝"？**
A：三定位——前驱 pre（提前走 left−1 步）、区间头、区间尾；区间内就地反转（改箭头不删节点）；两刀接缝——pre 接反转后的新头、原区间头接 right 的后继。循环故意漏区间尾，退出后补刀。#92 四版磨出来的。

## 二、Python 语言坑（14 张）

**Q11 / 和 //？版本坑？**
A：`/` 真除法永远 float；`//` 地板除 int。力扣选 "Python"(=2.7) 时 `/` 是整除能过，Py3 必炸——二分 mid 必须 `//`。

**Q12 类 vs 实例一句话？**
A：类名**无括号** = 图纸（赋值只是别名）；**有括号传参** = 调 __init__ 造盒子。两次踩坑（LLM_client、ListNode）。

**Q13 变量三权分立 + 反面？**
A：一变量一职责，乱不乱看职责归属（chatbot 的 messages、#977 的 i）；反面：职责重合就合并（#58 反向版 t/tmp 恒等，单变量够）。

**Q14 `result = nums` 会怎样？**
A：贴标签不拷贝——写 result 就是写 nums，原数组被污染。独立副本：`[0] * n`。

**Q15 字符串 s[::-1] vs reversed(s) 内存？**
A：字符串不可变，切片必须整串复制（峰值 ×2）；reversed 是游标 O(1) 按需吐。顺序单遍用 reversed，要反复用/随机访问才切片。

**Q16 append / sort 的返回值？**
A：None（原地修改）——别赋值回去（`self.history = history.append(x)` 双重错）。

**Q17 `2^16` 在 Python 是多少？**
A：18（^ 是异或）。幂是 `2**16` = 65536。

**Q18 Python 负索引的险处？**
A：`nums[-1]` 不报错、摸末位——越界错误悄然发生。先判界再访问（#66 的 len1==0 拦截）。

**Q19 except 后面接什么？接错了怎样？**
A：**异常类名**（traceback 最后一行、冒号前面那段）。接方法调用/数字 → NameError/TypeError；让报错"招供"再原样抄——这是找异常名的通用套路。

**Q20 裸 except 的罪？**
A：吞掉 NameError、Ctrl+C 一切异常——程序假死还查不到错。**接什么写什么**，只接预期能发生的。

**Q21 方法（类里）能写 break 吗？**
A：不能——break 只属于循环体，写了直接 SyntaxError。方法用 **return 交还决策权**：把坏消息当返回值报上去，要不要退循环是调用方的事。

**Q22 `mylist[-5:]` 会改原列表吗？**
A：不会——切片**造新列表**，没人接住就蒸发（表达式必须有接收者）。改原列表要赋值回 `self.history = ...`。P1-① 首版就栽在这。

**Q23 `not self.history or ...` 为什么这么写？**
A：**or 短路**——history 为空时左边已真，右边 `history[0]` 不执行。先判空再取 [0]，IndexError 债就还在这行。

**Q24 参数化后漏写 self. 会怎样？**
A：chat 里用了 __init__ 的参数名 → NameError（局部变量出函数即死，实例属性住 self. 上）。注意：**每轮执行的那行马上炸，条件分支里的走到才炸**——分支内代码也要过变量名。

## 三、AI 基础（6 张）

**Q25 模型的"记忆"存在哪？**
A：不在模型里——在程序的 history 列表，每轮全量重发。模型每次都是初次见面。

**Q26 对话 1000 轮会发生什么？**
A：history 无限膨胀、成本平方级、超上下文窗口后报错或截断失忆 → Context Engineering 的动机。

**Q27 MCP 和 A2A 各管什么？**
A：口诀"MCP 调工具，A2A 调 Agent"。

**Q28 role 三标签分工？**
A：system 人设（1 条，最前）/ user 用户说的（每轮）/ assistant 模型说的（每轮）。贴错标签 = 人格劈叉。

**Q29 temperature 是什么？实验结论？**
A：采样随机度。实验实锤：0 = 收敛（同问基本同答）但不冻结；1.5 = 突发胡言（参数生效铁证）。0 也非绝对确定 → **LLM 非确定性 = 测试难/评测难的根源**。

**Q30 滑动窗口截断公式？为什么一刀保头？**
A：`self.history = [self.history[0]] + self.history[-(N-1):]`——保 system 头 + 最近 N−1 条，总条数 = 1 + N。一刀保头：先切丢再补回 = 三个补丁散三处，"谁负责谁知情"，截断该在类里一次做完。

## 四、工程实战（5 张）

**Q31 .gitignore 挡不住已跟踪的文件？**
A：对——ignore 只管未跟踪的。已 add 过的要 `git rm --cached 文件名` 请出仓库（history.json 载过）。

**Q32 写入的 git 地址和 -v 显示不符？**
A：全局 .gitconfig 里有 **insteadOf** 幽灵重写（加速教程残留，把 github.com 改写 gh-proxy）。查：`git config --get-regexp insteadof`。

**Q33 被 import 时不想执行主程序？**
A：`if __name__ == "__main__":` 护栏——直接运行时 __name__ = "__main__" 才进主程序；被 import 时只供货（类/常量）。pytest 测试全靠它。

**Q34 pytest 的收集规则和边界？**
A：从当前目录**递归收集**所有 test_*.py——根目录裸跑会扫进 refs/ 教程仓库（24 errors 教训）。`pytest.ini` 写 `testpaths = ai` 钉边界；collection≠执行，import 挂了测试根本跑不到。

**Q35 改完代码重跑、报错一字不差？**
A：先 Ctrl+S——**IDE 缓冲区 ≠ 磁盘**，pytest 跑的是磁盘文件。排障第一反应：确认改动真的落盘了。
