# hello-agents 课程学习计划（2026-09-05 版）

> **信息截至 2026-09-05**（依据当日 2 轮联网搜索 + JD 调研 + 教材源码核查，规则见 [AGENTS.md](AGENTS.md) 规则 1）。
> **定位**：本文件是 [roadmap.md](roadmap.md)（求职总战略）下的**课程攻略版计划**——教材为 Datawhale《hello-agents》，已克隆到 `refs/hello-agents/`。两文件冲突时以 roadmap.md 为准；本文件只回答一个问题：**这套 16 章的课，哪些精读、哪些快过、哪些按 2026 年新知识修正后再学**。
> 原有 [plan.md](plan.md)（算法节奏）、[daily.md](daily.md)（每日清单）均不受影响。
> **你的现状（2026-09-05 补记）**：2025 年已学完第 1~5 章，停在第六章——恰是过时最重的一章。所以本计划实为**"从第六章续学"计划**：前五章不复学，只做验收；真正要新学的约 11 章。

## 一、这套课怎么用（方法论）

1. **不平推**。前五章你已学过，剩余 11 章按"6 章精读动手 + 概念快过 + 选读 + 跳过"处理，排期全部嵌入 roadmap 已有时间槽，不新增时间块。
2. **边读边跑码**。教材配套代码在 `refs/hello-agents/code/`，每章读完至少把一个示例跑通再进入下一章。依赖按需 `pip install`（用根目录 `.venv`），不要一次性全装。
3. **在线版与勘误**：https://www.datawhale.cn/learn/summary/239 （PDF 免费下载）。

## 二、过时点诊断与 2026-09 修正（本文件核心价值）

> 教材主体成书于 2025 下半年，整体框架（范式→框架→协议→记忆→评估）依然有效，以下是逐处核查发现的时效问题。

| # | 教材原内容 | 时效判定（2026-09） | 修正动作 |
|---|---|---|---|
| 1 | 第六章以 AutoGen `0.7.4` 为例，称"截至目前最新版本" | 微软已将重心转向 **Microsoft Agent Framework**（AutoGen 与 Semantic Kernel 的融合方向），AutoGen 进入维护期 | AutoGen 小节**只读设计理念**（"对话驱动协作"），代码不跟敲——面试能讲清它和 LangGraph 的范式差异即可 |
| 2 | 第六章主推四框架：AutoGen / AgentScope / CAMEL / LangGraph | 2026 年招聘 JD 高频的是 **LangChain / LangGraph**（网易、滴滴等多家点名）；AgentScope/CAMEL 在国内 JD 中属小众 | **LangGraph 作为唯一动手框架**；另补两个认知级（会用≠要深学）：Claude Agent SDK（MCP 支持最深，增长最快）、OpenAI Agents SDK |
| 3 | 第六章 LangGraph 示例用 `workflow.set_entry_point("planner")` | 该 API 在 **LangGraph 1.x 已废弃**，书内另一处又用了新 API，版本混杂 | 一律替换：`add_edge(START, "planner")`；其余 v1 迁移要点（`Annotated[list, add_messages]`、`create_agent` 替代 `create_react_agent`）见 roadmap 阶段 1 防坑注记 |
| 4 | 第十章 MCP/A2A/ANP 协议解析 | MCP **最终规范已于 2026-07-28 落地**，教材写作时规范未定稿，细节可能有出入 | 协议细节以 modelcontextprotocol.io 官方文档为准，教材作概念入门；A2A 现属 Linux Foundation 体系 |
| 5 | 第十章 ANP 协议 | 探索性协议，生态小 | 读一页了解即可，零投入 |
| 6 | 第八章 RAG 覆盖基础链路 | naive RAG（切块+向量+生成）在 2026 年**只是面试入场券** | 课程打底后必须叠加：混合检索（BM25+向量）、重排序（bge-reranker 类）、RAGAS 思路评测——roadmap 阶段 2 已排，勿停在课程深度 |
| 7 | 全书未覆盖 AI Coding 工具使用 | 2026 JD 普遍把 **Cursor / Claude Code / Codex 深度使用**列为加分项甚至硬要求（滴滴 JD 直接要求"100% AI 编码实践经验"） | 日常开发刻意用 AI 编码工具并积累案例；Extra09《踩坑与经验分享》列入必读 |
| 8 | 第十二章讲评估指标，但无工程实践 | JD 高频"效果评测、评测集建设"；行业主线已从聊天助手转向**可治理的任务系统**（可观测、可回放、可审批） | 第十二章精读 + 1 月补 Langfuse（可观测）实操；评测闭环细节执行 roadmap 阶段 2 的"项目深度层"清单 |
| 9 | 第十一章 Agentic-RL（SFT→GRPO 训练实战） | 对应用开发岗过深，JD 不要求 | **降级为概念快过**（能说清 SFT/RLHF/GRPO 区别即可），与 roadmap 1 月微调入门合并消化 |

## 五、硬规则

- 每章收尾自测：**合上书口头讲清本章核心机制**（讲不清 = 没过，重讲）。
- 教材代码出 bug 先查版本差异（大概率是 #3 类 API 变更），再查 issues——这本身就是工程训练。
- 课程内容与 roadmap 冲突时（如框架选型、时间分配），**roadmap 优先**。
- 本计划每月底随 roadmap 复盘一次，过期情报（如框架格局变化）按规则 1 重新搜索校准。
