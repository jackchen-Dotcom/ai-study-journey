# 19. 删除链表的倒数第 N 个结点

- 题号: 19
- 难度: 中等
- 标签: 链表, 双指针

## 题面

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

示例：`1→2→3→4→5`，n=2，删除倒数第 2 个结点（4），返回 `1→2→3→5`。

进阶：你能尝试使用一趟扫描实现吗？

输入形式：`input = [链表列表, n]`，判题器自动把第 1 个参数转成链表（`"convert": "linkedlist"`），n 保持整数。

## 测试用例

```json
[
  {"input": [[1, 2, 3, 4, 5], 2], "expected": [1, 2, 3, 5], "convert": "linkedlist"},
  {"input": [[1], 1], "expected": [], "convert": "linkedlist"},
  {"input": [[1, 2], 1], "expected": [1], "convert": "linkedlist"},
  {"input": [[1, 2], 2], "expected": [2], "convert": "linkedlist"},
  {"input": [[1, 2, 3], 3], "expected": [2, 3], "convert": "linkedlist"}
]
```

边界坑说明：用例 2 单元素删头、用例 4/5 删头结点——`return head` 的写法会当场翻车；用例 3 是最普通的删尾。
