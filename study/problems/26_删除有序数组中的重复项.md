# 26. 删除有序数组中的重复项

- 题号: 26
- 难度: 简单
- 标签: 数组, 双指针

## 题面

给你一个**非严格递增排列**的数组 `nums`，请你**原地**删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度 `k`。

要求：
1. 不能使用额外的数组空间（O(1) 额外空间）
2. 数组的前 `k` 个元素必须是去重后的结果（后面的元素无所谓）
3. 返回 `k`

示例：`[1,1,2]` → 返回 `2`，且 `nums` 前 2 位是 `[1,2]`。

判题说明：用例带 `"convert": "array_mutate"`，判题器会同时验证你的**返回值 k** 和**数组前 k 位**，格式为 `[k, 前k位]`。

## 测试用例

```json
[
  {"input": [[1, 1, 2]], "expected": [2, [1, 2]], "convert": "array_mutate"},
  {"input": [[0, 0, 1, 1, 1, 2, 2, 3, 3, 4]], "expected": [5, [0, 1, 2, 3, 4]], "convert": "array_mutate"},
  {"input": [[1, 1]], "expected": [1, [1]], "convert": "array_mutate"},
  {"input": [[1]], "expected": [1, [1]], "convert": "array_mutate"},
  {"input": [[1, 2, 3]], "expected": [3, [1, 2, 3]], "convert": "array_mutate"}
]
```
