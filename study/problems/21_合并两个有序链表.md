# 21. 合并两个有序链表

- 题号: 21
- 难度: 简单
- 标签: 递归, 链表

## 题面

将两个升序链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例：`1→2→4` 和 `1→3→4` 合并成 `1→1→2→3→4→4`。

输入形式：链表以列表给出（判题器自动在 列表 ↔ 链表 之间转换，用例带 `"convert": "linkedlist"`）。

## 测试用例

```json
[
  {"input": [[1, 2, 4], [1, 3, 4]], "expected": [1, 1, 2, 3, 4, 4], "convert": "linkedlist"},
  {"input": [[], []], "expected": [], "convert": "linkedlist"},
  {"input": [[], [0]], "expected": [0], "convert": "linkedlist"},
  {"input": [[1, 2, 4], [1, 3, 4, 5, 6]], "expected": [1, 1, 2, 3, 4, 4, 5, 6], "convert": "linkedlist"},
  {"input": [[-5, 0, 3], [-10, -2, 7]], "expected": [-10, -5, -2, 0, 3, 7], "convert": "linkedlist"}
]
```
