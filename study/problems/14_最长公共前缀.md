# 14. 最长公共前缀

- 题号: 14
- 难度: 简单
- 标签: 字符串, 字典树

## 题面

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

示例：`["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`。

提示：`1 <= strs.length <= 200`（数组至少有一个元素，但**不保证所有字符串非空**吗？——力扣保证每个字符串长度 >= 0，思考空字符串会不会成为某个元素）。

## 测试用例

```json
[
  {"input": [["flower", "flow", "flight"]], "expected": "fl"},
  {"input": [["dog", "racecar", "car"]], "expected": ""},
  {"input": [["ab", "a"]], "expected": "a"},
  {"input": [["interspecies", "interstellar", "interstate"]], "expected": "inters"},
  {"input": [["a"]], "expected": "a"},
  {"input": [["", "b"]], "expected": ""}
]
```
